## What each kind of evidence can support

| Evidence | Can support | Cannot establish alone |
| --- | --- | --- |
| Named source/HTTP check | The invariant and build actually exercised | Pleasure, discovery or social meaning |
| Scripted browser path | The actual action sequence at stated viewports | Unprompted success by unfamiliar friends |
| Actual-image review | What the captured frame visibly shows | Musical quality or all future viewpoints |
| Human listening | A named listener's judgement of named material/settings | Every arrangement or playback device |
| Two-pair observation | What those four people found and misunderstood | A population-wide usability result |
| Process restart | Persistence across the tested restart | A real next-day return |

A passing total, generated concept image or agent completion message cannot
substitute for a different category. The latest frog rejection is actual author
feedback; it does not amount to approval of the replacement or complete mix.
No unfamiliar-pair, physical-phone or next-day finding has been supplied.

## Evidence categories used throughout

| Category | What it supports | What it cannot establish |
| --- | --- | --- |
| Automated source/HTTP check | A defined invariant for a named source/build | Pleasant sound, understandable onboarding, human cooperation |
| Automated browser path | A scripted flow in a stated browser/viewport | Unprompted discovery by new people, physical-phone performance |
| Developer/agent visual review | What a reviewed real screenshot actually shows | Artistic approval by the author; musical listening |
| Human listening | A named listener's judgement of named audio at stated settings | General usability or all-device audio quality |
| Unexplained two-person playtest | What those participants discovered and misunderstood | A population-wide result from two pairs |
| Restart check | Recovery after an actual process restart | A next-day return that has not happened |

Do not turn a generated concept image, silent geometry fixture, screenshot of
a trace, total test count, or agent completion message into evidence for a
different category.

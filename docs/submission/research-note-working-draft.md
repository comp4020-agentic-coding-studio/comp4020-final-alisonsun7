# Research-note review outline

The canonical draft is [the root research note](../../research-note.md).
Updated 2026-11-08. It synthesizes the two previously selected directions into
one position: production requires claim-specific verification capacity, and
responsibility for the standard of good cannot be delegated to a passing score.

The argument compares practitioner mechanisms with a randomized result and
its later measurement limits, then meets the counterargument that agents can
also verify. It proposes a bounded acceptance practice and a way to challenge
its costs. This is a field-level argument, not a Little Chorus success report.

[The source audit](source-verification.md) verifies titles, authors, dates,
types and limits from primary pages. Before sign-off, answer
[question 3](final-author-checklist.md). Reading supplied by an agent is not a
claim that the author personally read it. Revise the thesis if it is not a
position the author can explain and defend.

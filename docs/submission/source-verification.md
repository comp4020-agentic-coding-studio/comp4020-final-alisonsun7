## Course requirements

The [final-project brief](https://comp.anu.edu.au/courses/comp4020-agentic-coding-studio/assessments/final-project/)
assigns COMP8020 process/application/response/research weights of
35%/20%/20%/25%, and reference lengths of 400–600/900–1100/600–800 words for
the three root texts. The note must defend a literature-based position beyond
the project. README, agent rules, checks and app should express the same idea.

The [assessment page](https://comp.anu.edu.au/courses/comp4020-agentic-coding-studio/topics/assessment/)
identifies the course Fly URL as the submitted application and specifies
1920×1080 and 390×844 Chrome marking viewports. Local preview evidence alone
therefore leaves a deployment gap.
Its word ranges are indicative guidance, with no automatic length penalty;
poor scope can still affect the response judgement. Bibliography exclusion is
not explicitly specified, so the packet reports its own count boundary.

The [AI-use and integrity policy](https://comp.anu.edu.au/courses/comp4020-agentic-coding-studio/topics/ai-use-and-integrity/)
allows AI assistance and drafting, requires an accurate account and the ability
to explain the work, and does not demand a model citation for every generated
code fragment. The brief advises author-drafted prose. Here the author explicitly
authorized first-person assistance; the draft notice and review questions keep
that assistance separate from author approval. False experience remains false
even when an agent drafted it.

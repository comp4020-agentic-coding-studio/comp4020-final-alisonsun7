# Evidence entry template

Append real entries to the existing evidence log; do not replace history. No actual event is implied by this template.

- Stage and timestamp/timezone:
- Goal and relevant promise:
- Consequential actual prompt/reference:
- Inputs/code/docs actually inspected:
- Option chosen, alternative and cost:
- Implementation paths:
- Actual command results, not expectations:
- Actual browser context/viewport/timing observation:
- Production URL/commit/volume observation, if made:
- Failure/rejected attempt and whether code/test/environment:
- Fix and corresponding harness/check change:
- Real commit/compare link:
- Push/CI/deployment status (separate):
- Human judgement/peer observation if actually made:
- Remaining unverified claims:

No tokens, private cookie jars, DB dumps or raw request bodies. Capture a screenshot only if it supports a particular claim; it cannot by itself prove restart durability. Inherited reports stay labelled until verified. Avoid backdating and fake incremental history.

Repeated tests with no code change are not new progress. New risk, failed check or changed logic justifies verification. Log observed findings clearly enough to support the student process account without a massive transcript dump.

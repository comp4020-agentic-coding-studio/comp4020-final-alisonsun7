# Grounded world — measured repair and actual preview

This archive preserves actual outputs from the 2026-11-08 support/light work,
including accepted scratch candidate `8f32290`. It is not the promotion release
index. `pure-checks.json` records byte hashes,
executing-agent-confirmed commands, counts and scope. Archival itself reran
no tests, server or browser. No database, cookies, environment/authentication
files or server logs are copied.

  union error. The final empty typecheck output has an executing-agent-confirmed

## Paired final support geometry

`support-audit.mjs`, the two `support-*-final.json` files and their actual stdout
compare pre-support compiled geometry with repaired geometry using the same
mesh corners, rays and six standing-character sites. The final checks pass
thirteen in two files; frozen pre-support geometry fails eight and passes five.
The earlier eleven-case negative (six fail/five pass) and initial current run
(nine pass/two fail) remain distinct. The latter exposed an actual café chair
straddling a step and an overly strong shallow-embedding assumption for a pole
intersecting the stage plinth.

This final audit covers twelve bench feet and twenty-one lantern feet at their
corners. Worst positive corner gaps go from 45.18 cm and 53.78 cm respectively
to below the 2 mm acceptance threshold. Its six paired standing sites reduce
maximum absolute sole separation/penetration from 10.32 cm to below 1 mm.
These are different samples from the initial eight Green leg-base centres
(25.9–29.1 cm) and original terrace-normal examples; do not mix those groups
into a before/after comparison.

Twenty-one actual foundations contain 1,576 vertices/triangles, with 110 contact
anchors. The café floor remains raised: its underside-to-earth maximum still
measures 1.357 m. Foundations fill that space; the repair does not lower the
historical floor by 1.36 m. These are geometry results, not visual acceptance.

`command-status.json` records typecheck, build and diff-check exit zero for
committed source `8f32290`. It accompanies the two empty final stdout logs;
neither empty file alone establishes success. The later completed source/GPU
paths are archived separately below, preserving the earlier run boundaries.

## Accepted final candidate, promotion evidence still separate

`final-full-spec.txt` passes 369/369 checks in 57 files, 71.41 s, on isolated
18931. `final-browser.*` passes eighteen rendered developer checks on 18932,
capturing nineteen frames. Seventy-five actual rendered walking samples cross
all five visible café steps; the observed transitions avoid a ground-fallback
drop. Four real time/weather requests succeed, existing sound rows remain
byte-for-byte unchanged, and no source is created, moved or removed. Join,
movement and environment requests do occur. There are zero browser/shader
errors in this path.

The seven `final-*.png` files come directly from this final-artifacts directory:
Green desktop, café desktop/phone, café night desktop/phone, entrance desktop
and conservatory rain desktop. Desktop is 1920×1080; phone is 390×844 with native
CDP touch on this Mac's Chrome, not a physical phone. The two approximately
1.2-second samples near 60 fps are not long-session performance or user review.

The separate `side-entry-audit.*` verifies nine compiled-module correspondences
to `40ed231`/`8f32290`, then uses actual geometry and the original movement
function on CPU. Two points about 5 mm apart have old heights 0/0; the new
stair footprint gives 0.065/0.57386 m, and a 12 mm move accepts the side climb
through the ray-confirmed foundation. A different old deck edge already had
a 0.70695 m discontinuity. The historical limitation does not make the new
side entry physically correct. This scope retains auto-step without gravity;
a valid front-stair walk is not a physics/collision repair or a guarantee for
every drop. The probe uses no GPU, service or database.

## Actual preview, preserved data and rollback

`promotion.txt` and `promotion-record.json` record the accepted `8f32290` local
switch at 18861, retaining all existing rows across twelve tables and checking
68 actual served assets/cache policies. The previous compiled app is `40ed231`.
Use `python3 scripts/local-preview.py --rollback` from the project to switch
application code with the current database, never the recorded backup database.

`promoted-browser.json` is a separate inspection after that switch: anonymous
and quiet, with every non-GET/HEAD request rejected. It passes with zero writes
and errors, sixteen current public source IDs retained, twelve resident rigs
and 383 actual far-shore render samples outside the planet. The four
`promoted-*.png` files show this actual version: Green, café desktop/phone and
the end of continuous coast walking. The local switch is not a hosted release.

Neither scratch acceptance nor these files establishes artistic listening,
unfamiliar-player understanding, physical-phone usability or next-day retention.
Frozen fixtures/configs keep their original cache-relative paths; they are
provenance, not silently rewritten standalone replay packages.

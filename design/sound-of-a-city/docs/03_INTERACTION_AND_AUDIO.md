# 03 — 声音、会话及交互行为规格

## 进入流程
1. 选择场景与模式；角色昵称可匿名随机，界面不能强制账号。
2. 初始世界视觉存在，但**没有由玩家提交的声源**；可选轻环境默认静音，UI 清楚说明。
3. 浏览器不允许自动播放带声内容时，提供 `Enable Sound` 用户点击；不点击也能视觉操作。
4. 支持选择音效 → 拖至允许热点（移动端先选音效再点位置）→ 预览 → 确认添加。
5. 通过键盘导航声源，Enter 放置，方向键/可访问控制调值，Delete 移除自己的贡献。
6. 同房间内观察到其他用户的更改和在线状态；远端同步不触发未经用户许可的音频播放。

## 声音参数
`id`, `soundId`, `ownerId`, `anchorId`, `xNormalized`, `yNormalized`, `gain(0..1)`, `pan(-1..1)`, `loop`, `startOffsetMs`, `endOffsetMs?`, `createdAt`, `revision`。
- 每个 soundId 有固定许可明确的音频文件/原创 Web Audio 合成或确定性临时样例。
- 每个 sound 有合理最大同时播放量；合理限幅避免声音总和过载。
- “音量降低/离开房间/隐藏页面/停止会话”应正确释放/暂停 AudioNodes；不能多次叠加泄漏。
- 单声道素材应支持 stereo panner；室内可轻微卷积/延迟，但不能导致严重延迟或 CPU 负担。
- 录音若有语音，不得默认发布到公共 Archive。

## “声音唤醒 NPC”规则
属于产品艺术表达，不声称真实 ANU 学生一定如此行为。
| 场景 | 用户添加声源 | 可见反馈 |
|---|---|---|
| Chifley morning | footsteps | 偶尔经过的 NPC 出现可听脚步 |
| Chifley weekday | bicycle | 一位骑车 NPC 沿路径经过，声音随其移动 |
| Chifley rainy | rain | 按天气变换为跑步、撑伞或躲雨的动画；当路径涉及水坑时出现踩水声 |
| LAB | espresso | 咖啡师开始一次短暂制作动作 |
| LAB | chatter | 对应座位的 NPC 有低声交流动作 |
| Marie | microwave | 角色靠近现有微波炉并进行加热流程 |
| Marie | sink-water | 角色在水槽前接水/洗杯 |
| Marie | elevator | NPC 停在电梯前，门响后进出 |
| Marie | typing | 高桌/座位旁 NPC 低头学习 |
规则要可预测且可暂停；没有声源时人物仍可做低强度无声待机动画。

## 三分钟 session
- `idle`：用户可查看场景和选声源，无录制时间线。
- `active`：服务器记录 `startedAt`, `durationMs=180000`，所有参与者看到同一倒计时，不依赖每个客户端自己的 180 秒计时。
- `ending`：服务器封存操作序列，禁写/只允许确定性终止动作，处理并发一致性。
- `saved`：事务性保存 `memory`，只读回放 URL 可访问；不能将未经审核音频自动公开发布。
- `failed`：可重试，不丢原 session 的可恢复数据。
- `solo`：独自体验仍可以创建 session，但提示邀请其他人的益处；评估双人时两人必须同步。

## 冲突与幂等
- 每个写请求携 `operationId`（UUID），服务端记账，重复 op 不重复插入。
- 以服务器 authoritative state + revision 更新；编辑失效需要回显最新状态，不得将本地 optimistic state 冒充已保存。
- 多人试图同时拖动同一声源：默认 owner-only 编辑或 lease-based lock；P0 优先 **creator controls own sound, others can add complementary sound**。可加入管理员/共同编辑为 P1。
- Presence（光标/在线人数）是临时数据；实际声源必须落盘。

## 音频回放与记忆
- 保存“已授权声源的标识和参数 + 按时间排序的操作时间线”，而不是必须编码一整个 180s 视频/MP3。
- 回放按保存数据重新构建状态，拖拽与音量变化应能够按时间重现；若 P0 时间不足，可以保存最终场景并提供「从头听最终组合」回放，明确标注没有完整编辑过程回放。
- 音频缓存失败显示可识别提示，其他声源可继续播放。
- 记忆链接包含场景名称、模式、UTC 时间、贡献者昵称、素材许可、非官方学校项目声明。

## 用户自录
P2 默认：用户主动授权麦克风 → 本地录制上限 15s → 提示「确认你拥有版权，且没有未经同意的可辨识私人对话」→ 私有试听/存储 → 提交公开前另一步授权。
严格验证 MIME、长度、存储配额、安全文件名、内容尺寸和错误状态。对隐私/版权没有审核能力时只实现“本地试听”，不开放公开上传。

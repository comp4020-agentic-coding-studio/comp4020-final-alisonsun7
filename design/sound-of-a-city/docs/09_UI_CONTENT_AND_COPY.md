# 09 — UI 页面与文案规范

## 主视觉
场景占视口 80–90%；所有控件可折叠，不让面板挡住真实照片特征。字体用现代轻量无衬线；配色来自木饰面琥珀、雨天青灰、校园绿色、磨石地面灰。页面有电影片头的安静与节奏，不要过度黑科技 UI。

## Landing
主标题：`Sound of a City`
副标题：`A campus comes alive through the sounds we leave behind.`
说明：`Walk through ANU, add an everyday sound, and create a shared memory of place.`
按钮：`Enter the Campus` / `How it Works`。
显著写：`An independent student project inspired by ANU.`

## Scene selection
卡片：`Chifley Path` / `LAB ANU` / `Marie Reay — Ground Floor`；附可核对的实景对应资产。
Chifley 模式：`Early Morning` / `Busy Weekday` / `Rainy Dusk`。
LAB & Marie：默认 `Everyday`，不要无依据添加时间模式。

## Scene UI
顶部：Back | 场景名 + mode | online participants | Audio on/off。
主要画面：hotspots/音源细点，NPC，用户头像。
底部折叠 sound tray： `Add a sound`，分类：Nature / People / Movement / Places / Objects。
侧边可折叠：`Now playing`, `Your sounds`, `Others' sounds`。
Session 控件：`Start a 3-minute memory` → `Time remaining 02:59` → `Save this memory` → `View memory`。

## UX 提示
- 初始空场景：`This place has its shape, but not yet its sound. Add the first everyday moment.`
- 音频需授权：`Tap to enable sound.`
- 声源拖放提示：`Choose a place for this sound.`
- 位置非法：`That sound belongs in another part of this scene.`
- 同步等待：`Saving your sound…`
- 成功：`Sound saved. Everyone here can hear it.`
- 断网：`Connection lost. New changes aren't saved yet.`
- 冲突：`Someone changed this sound. We've reloaded the latest version.`
- 结束：`A place, made alive together.`
- Archive：`Every visit leaves a different soundscape.`

## 不使用的东西
- 不要大型游戏 HUD、比分、金币、排行榜或平台风弹窗。
- 不要误导为官方 ANU 导览网站。
- 不用侵入性自动播放、无法关闭的录音、没有证据的 exact 3D floor plan。
